About a week into my code learning journey I got a tip from a friend. He shared
his repo where he'd stored all his leetcode solutions. This was brilliant. The
site itself is pretty easy to use, but taking the time to copy out my solutions,
then work through commenting them, and saving them somewhere I could share? A no
brainer.

After setting up my own repo of solutions it dawned on me: I might like to write
a bit about my journey. I'm sure no one will read it. All the better. The
internet needs more personal websites.

So, this blog was born. The idea progressed like this:

* I'm gonna blog my coding journey
* I'll call it a diary, not a blog
* I'll hook up my solutions repo to automaticall pull in code snippets to posts
  (calm down! you don't even have the thing set up yet)
* Use Hugo! I've always loved ssgs, never really had a chance to use one.
* Hugo docs are... difficult. Nothing is wokring the way I want
* Keep it simple. Just add some posts and some problem pages.

And thus, this blog was born.
